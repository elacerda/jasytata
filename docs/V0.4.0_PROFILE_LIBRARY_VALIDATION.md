## Decision and repository baseline

This is the authoritative Gate 6C evidence record. Gate 6C is **not complete**:
the frozen release selected one CALIFA/PPAK profile and five MaNGA bundle

## Source and provenance audit

All 16 bundled v3 instruments and the SAMI v3 strategy list primary references.
Their required geometry/sequence parameter paths have unique parameter sources
that resolve to those references; registry registration runs the strict v3
validator on every bundled object. Derived values are named in their parameter
notes: angular-unit conversions, half-diameter radii, area-equivalent radii, and
polygon vertices derived from a stated circumradius. The LVM source's 30.2′
outer diameter resolves the selected approximate envelope radius; its reported
15.4′ side/0.165 deg² values are not used to manufacture an exact fibre mask.
The 4MOST canonical regular hex follows the later frozen Gate 2 contract's
2.5° circumscribed-diameter choice; the older matrix uncertainty about convention
is retained as historical research evidence and is not treated as an active-area
claim. PFS uses the primary source's explicit circumscribed diameter.

CALIFA/PPAK's cited primary evidence gives approximate rectangular extents and
fibre layout, not exact regular-hex vertices. MaNGA's primary instrument page
gives nominal diameters but does not establish whether they describe a
circumscribed or flat-to-flat boundary for the required polygon. The independently
validated Gate 3 record remains binding: no exact fixture was frozen, so no
geometry is reverse-engineered. Gate 5's CALIFA and MaNGA sequence tests remain
runtime-fixture evidence only; no strategy is registered without its selected
instrument profile. This is a release-evidence blocker, not a proposal to weaken
those profiles to rectangles or to change their fidelity.

This is an evidence/parameter gap, not a contradiction in Gate 2's selected
instrument/strategy intent: Gate 2 selects approximate hexagonal planning
envelopes and the named sequences, but the cited dimensions do not determine
the required six polygon vertices. Gate 3 explicitly withholds any exact vertex
fixture and forbids deriving vertices from extents alone. The frozen release
selection therefore remains in force, while these six data records cannot be
honestly instantiated until an authoritative source resolves their boundaries.
They are not marked deferred by the release contract. Schema v3's existing
polygon and observing-sequence semantics can represent them once sourced; this
is not a Gate 6A/6B abstraction gap.

## Lifecycle, coverage and mixed-profile evidence

- The instrument-only matrix round-trips all 16 production v3 instrument
  documents through canonical serialization, strict parsing, fresh-registry
  registration, manual/imported source assignment and source-footprint
  resolution. The instrument remains usable without a survey registration.
- A per-profile Gate 6B loop measures each of the 16 bundled v3 instruments
  using its declared coverage role. Observed-area profiles return authoritative
  observed metrics when resolved; nominal envelopes return only explicitly
  non-authoritative envelope metrics; target-access profiles return no
  contributors for observed-area measurement. Required per-pointing PA is
  supplied explicitly in these fixtures.
- The strategy-bearing matrix round-trips the SAMI instrument/strategy pair,
  resolves seven ordered effective-sequence geometries, and measures the
  selected `nominal_envelope` basis without setting
  `authoritative_observed_area`. The strategy has manual tiling and disabled
  inference; its dither sequence is not a survey lattice.
- Target-access regressions exercise both PFS and 4MOST through Gate 6B. Each
  alone yields `no_contributors` for observed-area metrics, and adding either to
  KCWI produces the same observed result as KCWI alone.
- OmegaCAM's nominal-envelope fixture produces a separately labeled
  non-authoritative envelope metric. Adding it to observed-area KCWI coverage
  leaves the observed metric unchanged.
- A synthetic large observed rectangle plus the real KCWI small profile proves
  smallest-contributor mixed-scale resolution. A sequence-bearing synthetic IFU
  plus an ordinary KCWI source resolves sequence geometry for the former and one
  geometry for the latter, without ID-dependent runtime behavior.
- A selected SAMI sequence resolves on a small representative region. A broad
  mixed-scale fixture returns explicit `under_resolved` with no selected or
  remaining coverage fraction. The hard sample budget was not raised to force a
  resolved answer.

## Export behavior and genericity evidence

The existing export builder now dispatches to the strict v2 or v3 strategy
validator by the declared schema version, then uses the same generic CSV
serializer. Its previously v2-only boundary was reproduced with a failing v3
sequence export regression before this generic fix. An API regression exports
the selected SAMI seven-position sequence in deterministic order with RA/DEC,
configured exposure IDs, and profile-declared instrument/strategy constants.
The SAMI CSV has no PA column and no fabricated zero PA. Existing T80
sexagesimal output and v2 export fixtures remain unchanged. Sequence rows still
expand only when the runtime explicitly supplies a sequence resolver; no
facility-specific command format is implied.

The cross-profile tests cover rectangle, circle and polygon geometries; exact
and approximate fidelity; all three coverage roles; fixed, per-pointing and
not-applicable PA; no sequence and ordered sequence; standalone and
strategy-bearing lifecycle. They alias production profiles to ordinary test IDs
before exercising generic footprint/PA resolution. No production scientific
branch was added for KCWI, SAMI, PFS, 4MOST or any survey identifier.

### Final scientific review

1. **Authoritative source per bundled profile:** yes; every v3 profile names a
   primary reference and parameter source. Six selected bundles remain blocked
   because their primary-source dimensions do not specify required vertices.
2. **Numeric geometry:** supported directly, or derived by documented unit,
   half-diameter, area-equivalent or regular-hexagon formulas. No CALIFA/MaNGA
   vertices are invented.
3. **Derived data:** parameter notes state formula and input convention.
4. **Approximation labels:** every approximation/envelope/access profile carries
   an explicit notice plus assumptions and limitations.
5. **Role:** KCWI is observed area; camera/bundle envelopes are nominal;
   4MOST/PFS are target access.
6. **Target access in observed metrics:** no; tested for both selected access
   profiles.
7. **Nominal envelope as exact active area:** no; the profiles and metric role
   remain explicitly approximate/non-authoritative.
8. **Fake survey:** none; SAMI is the selected named strategy, S-PLUS is the
   protected existing survey, and instrument-only data have no synthetic
   strategy.
9. **Invented lattice:** none; instrument-only placement is manual. The SAMI
   sequence is not a lattice.
10. **Dither as placement:** no; ordered exposure geometry remains separate from
    manual pointings.
11. **PA:** frozen modes use their selected policies. Required PA is supplied
    per pointing for MUSE/PFS/4MOST; canonical omitted orientations are not
    exported as physical PAs.
12. **Absent PA as zero:** no; SAMI export and required-PA failure tests cover
    this boundary.
13. **Instrument-ID scientific code branch:** none added; registry installs
    declarative profiles and runtime uses profile fields.
14. **Hector/SAMI full plates:** still deferred; only the selected individual
    bundles are present.
15. **T80/S-PLUS output:** unchanged and covered by focused/full regression tests.
16. **V2 meaning:** unchanged; old KCWI v2 JSON remains separately valid and
    T80 remains v2.
17. **V3 round trip:** every bundled instrument and the SAMI pair round-trip
    without semantic loss.
18. **Gate 6B under-resolution:** hard budget and no-fraction refusal remain
    intact and are exercised by broad-region mixed geometry.
19. **Gate 7 work:** none; `frontend/src/styles.css` is unchanged.
20. **Release selection accounting:** all frozen cases are listed above, but six
    selected cases are not bundled or frozen-deferred. Therefore release
    selection accounting and Gate 6C acceptance are incomplete.

Final state must retain branch `0.4.0`, the protected untracked `.codex/` and
`poly.txt`, and no commit or push. Gate 6C and overall Gate 6 must remain
incomplete until the six selected polygon boundaries are supported or the
authoritative release contract explicitly defers them.

# Jasytata v0.5.0 real-browser validation checklist

Run this checklist against the exact local `0.5.0` release-candidate commit
recorded in `V0.5.0_GATE8_RELEASE_VALIDATION.md`. Record browser, OS, viewport,
date, each result, and any screenshots or console errors. Do not mark Gate 8
accepted until this checklist is completed in a real browser.

## General layout

- [ ] Left and right panels remain usable when their content exceeds the viewport.
- [ ] Essential controls remain reachable; scrolling has no unwanted nested or awkward behavior.
- [ ] Layout remains usable at ordinary desktop widths and a narrower desktop width.

## Aladin map

- [ ] Plain wheel and touchpad scrolling over the map scroll the page without a large accidental map zoom.
- [ ] Ctrl/Meta + wheel intentionally zooms the map; native zoom buttons also work.
- [ ] Pan works, polygon selection works, and Escape/cancel exits selection cleanly.
- [ ] The reference marker appears with its label and clears without changing scientific inputs.

## Region tools

- [ ] Draw and finish a polygon; cancel, redraw, and clear it.
- [ ] Create a rectangle from opposite corners.
- [ ] Create a rectangle from center and size using degrees, arcminutes, and arcseconds.
- [ ] Inspect an RA-wrap region across 359.9°/0.1° for a narrow, continuous visual shape.

## Project lattice

- [ ] Preview rectangular, triangular, and advanced bases.
- [ ] Check independent rotation and follow-instrument-PA rotation.
- [ ] Check region-center and fixed-coordinate origins.
- [ ] Toggle Preview lattice visibility; candidate markers remain visually distinct from generated proposals.

## Planning and proposals

- [ ] Run MUSE WFM, KCWI, and a wide-field imager workflow.
- [ ] Run Complete and Efficient and inspect generated proposals.
- [ ] Accept, cancel, and remove proposals.
- [ ] Change a planning dependency and verify stale plan/proposal state does not return.

## Observing sequences

- [ ] Run one SAMI, CALIFA, or MaNGA sequence workflow.
- [ ] Compare nominal-pointing and expanded-exposure counts.
- [ ] Download and inspect separate nominal-pointing and expanded-exposure CSVs and their row order.

## Project manifest

- [ ] Download `jasytata-project.json` and confirm its version, format, and schema fields.
- [ ] Import it with the browser file picker and regenerate the plan.
- [ ] Import an invalid file and confirm a useful error with the current project intact.
- [ ] Complete an export/import round trip and compare canonical inputs and planner output.

## Performance and cancellation

- [ ] Keep a large/dense lattice responsive while previewing and planning.
- [ ] Confirm Worker planning does not freeze the interface excessively.
- [ ] Cancel a run and change inputs during a run; no stale or partial result appears.

## Frozen S-PLUS and edge-region regressions

- [ ] Repeat the Galactic-center/S-PLUS-style region that previously showed bad tile proposals. Use its prior coordinates or `frontend/src/data/golden.json` → `historical_holdout.polygon` (RA 263.9327717371°–268.4338949295°, DEC −30.1830555556°–−27.3572222222°); record the exact vertices used.
- [ ] Repeat the previously problematic RA-wrap region if available. The manifest regression fixture spans RA 359.975°/0.005° and DEC −0.025°/0.005°; record the exact vertices used.
- [ ] Compare S-PLUS proposal order, coverage, and CSV export with the frozen regression evidence.

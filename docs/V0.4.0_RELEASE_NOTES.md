# Jasytata 0.4.0 release candidate notes

**Status: validated release candidate; not published.** This record summarizes
the selected v0.4.0 scope. Publication, tagging, deployment and merging remain
separate actions.

Jasytata 0.4.0 expands the browser planner from the protected S-PLUS/T80-South
workflow into a telescope- and instrument-agnostic profile library. The
candidate bundles 22 selected Schema v3 instrument profiles and seven named
observing strategies while retaining the original S-PLUS/T80-South Schema v2
pair as the default and preserving its legacy coverage and export behavior.

Users can plan manually with a standalone instrument and no loaded catalogue,
import and export validated instrument and strategy profile files, assign
different instruments to source catalogues, select a sky position angle when
the profile requires it, and inspect either a single exposure or the declared
ordered sequence geometry. Accepted pointings can be exported as generic ICRS
centers; strategy exports can explicitly expand one nominal pointing into its
ordered exposure rows.

Schema v3 records `observed_area`, `nominal_envelope`, and `target_access`
roles separately from exact or approximate fidelity. Only observed-area
profiles contribute to observed-area coverage. Approximate envelopes remain
explicitly non-authoritative diagnostics. Target-access geometry is never
observed coverage and does not imply fibre reachability, assignment, or
completeness. Mixed-scale sampling uses the smallest contributing observed
geometry; when the configured sample budget cannot resolve it, the result is
`under_resolved` with no authoritative percentage or completion claim.

This release does not provide a scheduler, fibre allocation, exact detector
masks for approximate profiles, full Hector or SAMI plate workflows, or a depth
or completeness claim from sequence geometry. It does not imply facility
command formats, universal regional tiling, or survey visit support. See the
[release validation record](V0.4.0_RELEASE_VALIDATION.md) for the complete
profile ledger, evidence, checks and limitations.

## Frozen orientation contract

Absolute and relative position angles use astronomical degrees east of north on
the ICRS tangent plane: 0° is north and positive angles rotate north toward east.
One canonical effective-pointing resolution path must supply the geometry used
by rendering, containment, region intersection, coverage, proposal preview,
accepted pointings and PA export. Its orientation input is the profile footprint
and the pointing's contract-resolved PA. Lattice basis orientation is not an
input.

| Policy | Effective absolute PA | Missing-value behavior |
| --- | --- | --- |
| `fixed` | Profile PA | Profile PA must be finite; conflicting row PA is invalid. |
| `user_selected` | One plan-level angle, defaulting to profile PA when present | Row PA is invalid; required missing value fails. No selected v0.4 profile currently uses this policy. |
| `per_pointing` | Explicit row PA, otherwise profile default | If required, absence fails. If optional and absent, retain canonical local east/north geometry without declaring a physical PA. |
| `not_applicable` | No physical PA | Profile and row PA are absent; export no PA. Use only for rotationally invariant geometry or an approximation that explicitly omits physical orientation. |

Required PA must be finite. An absent PA is not PA=0: canonical local
east/north orientation remains usable computationally where the policy allows
it, but there is no declared angle to export. Do not invent zero for an absent
angle. Equivalent input values (for example 0°, 360°, and −360°) must produce
equivalent geometry; persisted/displayed input representation is retained unless
an existing contract explicitly requires normalization. Effective composition
is normalized to `[0, 360)`.

Profile-fixed PA stays on the instrument profile. A per-pointing angle resolves
for that pointing and must not mutate the shared profile. Relative exposure
rotation is composed only with that pointing's resolved absolute PA. When the
absolute PA is scientifically absent, a relative rotation nonzero modulo 360° is invalid;
a full-turn-equivalent rotation preserves the absent PA and canonical footprint
orientation. This rule does not assign a physical PA to an envelope that omits
orientation. The selected CALIFA, MaNGA and SAMI sequence rotations are zero.

Lattice basis vectors place nominal pointing centers. Changing pointing PA must
not change centers or phase; rotating a lattice must not set footprint PA.
Inferred catalogue/lattice rotation does not populate pointing PA. A pointing
with exposures remains one lattice site and one proposal.

### Fixed, per-pointing and absent-angle checks

The independent fixed-PA fixture uses a non-square rectangle so a quarter-turn
is observable. It must compare analytic orientation with display boundaries,
containment, region intersection and coverage, while confirming unchanged
lattice centers. Equivalent angle inputs must agree geometrically.

The per-pointing fixture uses two pointings with one center and one shared
instrument profile but distinct allowed PAs. It must show identical centers,
different oriented geometry and expected intersection/coverage differences,
while the profile remains unchanged. Where export policy requests PA, each row
must carry that pointing's resolved declared angle.

The absent-PA fixture must prove that no physical angle or fake exported zero is
introduced, while geometry that is permitted without a physical PA remains
computable. The fixed and required per-pointing failure fixtures must reject
missing required PA and nonfinite PA.

Implementation evidence: `profiles/orientation.test.ts` validates policy
precedence, immutable fixed and per-pointing geometry, absent PA, nonfinite and
required-value failures, and equivalent angles. `science/pointing-geometry.test.ts`
compares non-square rectangle containment, intersection, and coverage masks at
fixed and distinct per-pointing PAs. `AladinMap.gate5.test.tsx` checks rendered
boundaries against the same resolver. `science/gate5-planner-context.test.ts`
checks preview versus accepted coverage with fixed and absent PA.

## Frozen exposure-coordinate and rotation contract

A Jasytata pointing has one nominal ICRS center, instrument mode, resolved PA
when meaningful/required, and selected strategy. Its optional strategy sequence
is a deterministic ordered list of exposures. Each exposure has a stable 1-based
order, local tangent-plane east/north offsets in arcseconds, and relative sky
rotation in degrees. These are derived exposures, not pointings, visits or
lattice sites.

For local `(east, north)` offsets `(e, n)` arcseconds, convert each component to
degrees by dividing by 3600, then use the same Jasytata tangent-plane-to-ICRS
transform used for local footprint offsets, centered on the nominal pointing.
Offset direction is sky-local and is not rotated by instrument PA or lattice
basis. Each exposure footprint center comes from that transformed offset; its
orientation is the resolved nominal PA plus the exposure's relative rotation,
normalized to `[0, 360)`, where an absolute PA exists. If the nominal PA is
absent, only a full-turn-equivalent relative rotation is valid; it keeps PA absent and preserves
canonical orientation. Relative rotation never changes the nominal PA or
instrument profile.

No sequence means historical single-exposure behavior: one exposure at the
nominal center with no relative rotation. Sequence validation must reject
nonfinite offsets, nonfinite/invalid rotations, a rotation nonzero modulo 360° when
nominal PA is absent, unstable or duplicate sequence identity/order, and any
malformed ordering that the runtime model represents.
The sequence model is independent of `TilingModel`; no offset can affect lattice
spacing, phase, inference, occupancy, anchors or candidate enumeration.

## Nominal geometry and effective-sequence coverage

**Single-exposure mode** evaluates the nominal footprint at the pointing's
nominal center and effective absolute PA (or the declared canonical orientation
when PA is absent and permitted). This remains centered on the nominal pointing
even when a sequence's first exposure has a nonzero offset, as in the MaNGA
north position. It is not a substitute for selecting one member of the sequence.

**Effective-sequence mode** is the deterministic geometric union of the
transformed footprints at the actual ordered exposure centers and orientations
belonging to one pointing. Overlap contributes once. It does not imply uniform
depth, fibre/spectroscopic completeness,
reconstruction fidelity, S/N, throughput or successful observing conditions.
For an approximate envelope it is an effective envelope union, not a measured
active-area reconstruction. A pointing with no sequence has exactly the
historical single-footprint geometry and coverage semantics. Existing source
catalogues without sequences continue to use this behavior.

Where safe, existing compound-footprint union machinery may be an internal
representation of the exposure union. It must not rewrite persisted instrument
geometry as a compound detector, and Gate 5 must not change T80/S-PLUS geometry,
the corrected v2/inline-v1 supplemental gap-fill distinction, or Gate 4 lattice
mathematics. Coverage remains subject to the existing sampling limitations;
mixed-scale sampling correctness belongs to Gate 6.

## Empirical sequence fixtures

These are nominal strategy fixtures, not claims of exact fibre-level observed
area. Their sequence inputs and limitations are frozen in the profile contract
and instrument matrix.

### CALIFA PMAS/PPAK three-position strategy

The selected `califa-ppak-three-point` strategy uses these ordered nominal
east/north offsets in arcseconds:

| Order | East | North |
| ---: | ---: | ---: |
| 1 | 0 | 0 |
| 2 | −5.22 | −4.53 |
| 3 | −5.22 | +4.53 |

Each relative rotation is 0°. The nominal instrument footprint is the
approximate 74″ × 64″ hexagonal PPAK science-bundle envelope. The source's
nominal offsets are sky offsets relative to the galaxy position; individual
measured object offsets can differ. This is the three distinct dither positions,
not the V1200 subframes taken at one position. Do not infer exact regular-hexagon
vertices from the envelope dimensions, or equate the effective envelope union
with reconstructed completeness. Sky/calibration fibres are excluded from
contiguous target coverage.

Primary sequence/geometry evidence: [Sánchez et al. 2016, CALIFA DR3, §3](https://openaccess.inaf.it/server/api/core/bitstreams/98310fc7-1b84-48e5-81c1-0010f6c9c85a/content).
Survey context: [Sánchez et al. 2012](https://arxiv.org/abs/1111.0962).

Fixture result: `science/exposure-sequence.test.ts` verifies three ordered
coordinates against an independent small-angle sky-offset calculation.
`science/pointing-geometry.test.ts` verifies the nominal footprint and three
derived placements using a synthetic rectangle sized to the sourced extent;
it does not assert PPAK hexagon vertices or fibre completeness. Shared union
masks and physical area are tested with overlapping and disjoint shapes.

### SDSS-IV MaNGA three-position strategy

Each selected bundle-size strategy uses one galaxy pointing with one ordered
N-S-E set and a sourced equilateral triangle side `a = 1.44″`. With centroid
`C` and local east/north coordinates:

| Order | Position | East (arcsec) | North (arcsec) |
| ---: | --- | ---: | ---: |
| 1 | North | `−a/(2√3)` | `+a/2` |
| 2 | South | `−a/(2√3)` | `−a/2` |
| 3 | East | `+a/√3` | `0` |

The offsets are centered: their vector sum is zero, and each pair is separated
by `a`. Relative rotations are 0°. A bundle remains one approximate nominal
hexagonal footprint with its existing bundle-size identity; its physical PA is
omitted under the frozen profile contract. A three-exposure set is the minimum
strategy unit; repeated sets require explicit additional ordered entries, not a
repeat-count inference. The 3° plate is sparse and outside this fixture.

Primary evidence: [Law et al. 2015, Fig. 6 and §3.4](https://research-repository.st-andrews.ac.uk/bitstream/10023/6906/1/law2015aj19.pdf).
Bundle sizes and source-specific fill-factor definitions are recorded in the
[instrument matrix](V0.4.0_INSTRUMENT_MATRIX.md).

Fixture result: `science/exposure-sequence.test.ts` verifies ordered N-S-E
coordinates, three 1.44″ sides, and the centered offset sum.
`science/pointing-geometry.test.ts` verifies a nominal center distinct from
the first exposure and three geometries under one pointing. The fixture
uses a synthetic circular bundle so bundle size and sequence remain independent.
`science/gate5-planner-context.test.ts` and
`science/gate5-planner-independence.test.ts` verify one nominal proposal per
lattice site and exclusion of exposure centers from inference.

### SAMI decision

The frozen contract selects a nominal SAMI DR1 seven-position strategy fixture:
central `(0, 0)`, then six nominal offsets at radius 0.7″ at 60° intervals.
The source establishes central-plus-six radial positions but does not establish
an absolute first angle or command order. The contract's canonical geometry
order starts north and proceeds eastward; this is a deterministic coordinate
normalization for envelope geometry, not an observatory command sequence. The
selected individual bundle has a circular approximate envelope, so this phase
does not change its geometric union. Published values are nominal guide-camera
offsets; atmospheric refraction and measured reconstruction alignments can
change realized offsets. Full plate support remains deferred.

Primary evidence: [SAMI DR1 observing-strategy documentation](https://sami-survey.org/system/files/papers/545/sami_dr1_6.pdf).

Fixture result: `science/exposure-sequence.test.ts` verifies center plus six
0.7″ radial offsets at canonical 60° intervals. The shared union tests verify
overlap counted once. This fixture makes no claim about executed observatory
order or full-plate coverage.

### MUSE and LVM scope conclusions

MUSE WFM/NFM documentation recommends multiple rotations and small offsets for
operational purposes. These recommendations do not establish a universal
instrument-level sequence. Retain required per-pointing sky PA for these
oriented nominal fields, but do not bundle a general MUSE sequence. The ESO
overview and phase-2 tutorial remain the geometry/operational sources in the
[instrument matrix](V0.4.0_INSTRUMENT_MATRIX.md).

LVM documentation describes different regional strategies (including
one-row-overlap, nine-point dither and sparse Orion plans). They do not define a
single universal instrument sequence. No LVM sequence or arbitrary local
tessellation is bundled; the authoritative tile list and region strategy remain
outside this fixture. See [Drory et al. 2024, §§IV.2–3](https://arxiv.org/html/2405.01637v1)
and the [SDSS DR19 LVM targeting strategy](https://sdss.org/dr19/lvm/targeting/).

## Runtime and persistence boundary

Gate 5 needs only the minimal runtime structures to resolve effective PA,
represent ordered derived exposures, obtain each exposure center/orientation,
compute single/effective union coverage, and preserve declared PA through the
currently supported pointing import/accept/export paths. A configured
`position_angle_column` exports the declared resolved pointing PA; if policy
requires a PA and it is missing or nonfinite, fail clearly. An absent/nonphysical
PA must not result in a synthetic zero column value.

The frozen contract assigns persisted v3 strategy sequences and profile document
validation to Gate 6, and sequence authoring/UI to Gate 7. Gate 5 does not add
undocumented CSV columns or persist a generic visit. Its PA export behavior must
respect the current documented column configuration and retain legacy v2 field
sets and T80/S-PLUS output. Exposure-row export uses only configured CSV columns,
with one row per derived exposure and a deterministic suffix in the configured
ID column. A multi-exposure export requires that ID column. It adds no profile
or tile persistence field. Runtime context callbacks must depend on stable
scientific attributes rather than temporary preview IDs to preserve
preview/acceptance parity; the planner retains its historical emitted IDs.

Import/export evidence: `science/catalogue.test.ts` covers recognized or
explicitly selected PA headers and required/nonfinite failures. The existing
`uploadCatalogue` browser path retains imported PA automatically when a supported
header is unambiguous. `science/export.test.ts` and `api.test.ts` cover configured
PA output, absent-PA failure, oriented exposure PA composition, deterministic
sequence rows, and unchanged T80 output. Runtime policy and strategy are
caller-owned through `PointingGeometryContext`; the v2 CSV path remains stable
when the context is omitted.

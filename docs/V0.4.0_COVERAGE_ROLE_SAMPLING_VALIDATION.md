## Scientific roles, basis and filtering

The frozen role vocabulary is unchanged:

| Requested `coverage_basis` | Eligible geometry | Interpretation |
| --- | --- | --- |
| `observed_area` | Only explicit v3 `observed_area` | Modeled science-active geometric union; resolved sampling permits an authoritative estimate with its error bound. |
| `nominal_envelope` | Only explicit v3 `nominal_envelope` | Explicitly requested nominal-envelope overlap diagnostic. It is never observed-area completion. |
| `target_access` | No area metric implemented | `unsupported_basis`; no fractions, fibre assignment or target completeness. |
| `legacy_v2` | Unclassified v2/v1 geometry plus explicit v3 observed-area geometry | Separately labeled compatibility union. V3 envelope/access geometry is excluded. No v3 role/fidelity is inferred into v2 data. |

V3 output defaults to observed-area measurement. Envelope planning requires
`PointingGeometryContext.measurementBasis = "nominal_envelope"`. V2 output
defaults to `legacy_v2`. A dataset containing only incompatible roles returns
`no_contributors` without any area/fraction fields. A valid empty calculation
may use the applicable output geometry/policy as its reference grid.

Membership is decided before resolving PA/sequences, geometric intersection,
scale selection, masks, contributor counts or greedy scoring. Only positive-area
intersecting eligible effective footprints determine resolution. Disabled
pointings are excluded. IDs never dispatch scientific roles. Tests cover observed
+ observed, observed + envelope, observed + access, access only and envelope only.
Tiny access/envelope footprints do not control observed-area pitch.

`contributing_semantics` exposes each contributing role/fidelity combination;
legacy entries have `role: legacy_v2`, `fidelity: null`. An approximate observed
model retains `approximate`, and an envelope never acquires observed semantics.
Geometry is separate from role, and geometric area is separate from depth or
spectroscopic completeness.

## Characteristic scale and resolution

Lengths are intrinsic tangent-plane degrees:

- Rectangle: shorter physical side.
- Circle: diameter.
- Polygon: minimum separation between parallel support lines of its convex
  hull, also for a concave polygon. Minimum width occurs normal to a hull edge;
  projecting all vertices on normals to all vertex pairs includes those edges.
  This corrects the old bounding-box rule without changing polygon geometry.
- Compound: minimum nonzero-area child scale, independent of component offsets
  or rotations. Gaps and holes narrower than this scale are not separately
  modeled by a new sampling rule.
- Sequence: minimum constituent exposure footprint scale, never total union span.

Let `s_min` be the minimum among eligible intersecting effective footprints.
The required pitch is `natural_step_deg = s_min / N`. V3 uses its frozen
`coverage.target_samples_per_footprint_axis >= 8`; v2 mixed runs use run-level
`N = 8`, optionally raised through `targetSamplesPerFootprintAxis`. No v2
profile is mutated. Ordinary generic single-scale v2 runs retain their policy
density with a runtime minimum of eight. Low-level generic sampling rejects
smaller density; the v2 validator itself is unchanged.

The existing sky model uses wrapped RA and the pointing-frame clamped cosine.
To enforce east pitch in every contributing frame, the generic sampler expands
the selected DEC range by the largest rotated north reach of the contributing
footprints and takes the maximum clamped cosine over that interval, `c_max`.
Any positive-area contributor's center is inside this interval. Thus:

```text
rows = max(1, ceil(DEC_span / required_pitch))
cols = max(1, ceil(RA_span * c_max / required_pitch))
actual_north_pitch = DEC_span / rows <= required_pitch
actual_east_pitch_at_any_contributor = RA_span / cols * cos_clamped(DEC_center)
                                   <= cell_width_deg <= required_pitch
```

This is a conservative resolution bound using the existing projection, not a
new spherical model. Integer subdivisions and row-major ordering are
deterministic; southwest half-cell centers, strict region masking and per-row
`cos(DEC)` weights remain. No truncation or stochastic sampling is used.

## Hard budget and result contract

`max_samples` bounds the whole rectangular principal grid, including exterior
zero-weight cells. Before allocation, the sampler calculates the required rows
and columns. If they exceed the budget, it may allocate a smaller **diagnostic**
grid, but its sampling status is `under_resolved`. Its raw arrays are never
accepted by metric calculation or greedy planning.

Resolved generic results carry:

- `coverage_status: resolved` and explicit `coverage_basis`;
- `authoritative_observed_area`, true only for resolved observed-area estimates;
- `geometry_basis`, contributing roles/fidelities and numerical error bound;
- `sampling.status`, `characteristic_scale_deg`, `natural_step_deg`,
  `effective_step_deg`, `cell_width_deg`, `cell_height_deg`,
  `east_projection_cosine`, `row_count`, `column_count`, `sample_count`,
  `required_sample_count`, `max_samples` and `budget_limited`.

Under-resolved high-level measurement returns only scientific basis/status and
sampling metadata. It has **no** selected/remaining area, already/final/incremental
fraction, redundancy or completion fields. `required_sample_count` is null if
its theoretical value cannot be represented as a safe integer; pitch, status
and bounded actual dimensions remain available. No coarse estimate or numerical
error claim is published by that result.

Complete and Efficient fail deterministically with `CoverageUnavailableError`,
whose `result` is the same machine-readable unavailable shape. Refusal precedes
mask scoring, completion decisions and marginal efficiency. `greedyChoose` and
`measureMetrics` independently reject an under-resolved grid. Explicit access
area planning and incompatible output roles are refused as `unsupported_basis`.
Resolved scoring, Efficient strict threshold comparisons and lattice sites are
retained. The existing API consumer narrows unavailable results before formatting
numbers; a browser regression verifies no final/remaining percentage or 100%
can be displayed from under-resolution.

Pure protected compatibility results have `coverage_basis: legacy_v2`,
`coverage_status: legacy_compatible`, no generic sampling/error metadata and
`authoritative_observed_area: false`. This status preserves historical estimates
without falsely declaring that historical budget coarsening met v0.4 resolution.

## Deterministic numerical error bound

The guaranteed bound concerns the **modeled** weighted RA/DEC domain, not exact
spherical sky area or instrumental fidelity. Let cells have RA/DEC widths `dx,dy`
and full diagonal `d = hypot(dx,dy)`, with a roundoff allowance. A cell intersecting
any boundary lies entirely within distance `d` of that boundary: every point in
the cell is at most a full cell diagonal from an intersection point.

For a straight boundary segment of coordinate length `L`, this neighborhood is
contained in a capsule of area `2*d*L + pi*d²`. Sum capsules for every selected
region edge and every rectangle/polygon primitive edge. For footprint edges,
rotation preserves physical length and RA stretching increases it by at most
`q = 1/max(cos(pointing_DEC),0.01)`. Using `q*L` therefore overbounds every
transformed edge, including compound child/parent rotations.

A transformed circle is an ellipse with curve length at most `q*2*pi*R`.
Its convex closed-curve tube has area at most `2*d*L + pi*d²`, hence
`4*pi*d*q*R + pi*d²` is a conservative bound. No display polygon replaces the
analytic circle. For frozen containment tolerances, enlarge the capsule radius
by the stretched tolerance: circles use `1e-12*q`, rectangles `2e-12*q`, and
polygon edges `2e-12*max(1,L)/L*q`, covering the existing cross/dot allowances.
Compounds and sequences sum constituent covers; overlap is deliberately
counted again in a bound, while coverage masks still count it once.

Let `B` be the smaller of the summed cover and full coordinate bounding-box
area. Since `0 <= cos(DEC) <= 1`, this also bounds weighted boundary-cell area.
For non-boundary cells, classification is constant but midpoint weight varies.
The global degree-coordinate derivative bound is `|d cos(DEC)/d DEC| <= pi/180`;
the maximum midpoint distance is `dy/2`. Therefore:

```text
weight_error <= coordinate_box_area * (pi/180) * dy/2
E = min(coordinate_box_area, B + weight_error)
```

`boundary_cell_area_upper_bound_deg2 = B`. For reported selected/covered/uncovered
area, `area_error_upper_bound_deg2 = E + 0.00005` includes historical rounding to
four decimals. For a union fraction `C/A`, both numerator and denominator
quadrature errors are at most `E`. With unrounded sampled denominator `A_hat`,
`A >= A_hat-E`; using `0 <= C <= A` gives a conservative ratio bound
`2*E/(A_hat-E)`, capped at one. If `A_hat <= E`, the bound is one. Add `0.000005`
for five-decimal fraction reporting, then cap at one. This is the reported
`fraction_error_upper_bound`. Area rounding is not fed into the ratio derivation,
because the runtime ratio uses unrounded quadrature area.

If an external low-level mask has no derivable footprint boundaries, or a
pointing's wrapped-RA antipodal discontinuity crosses the domain, use the entire
coordinate box as `B`: a rigorous but uninformative worst-case bound. Unsupported
geometry is not assigned a fabricated tight bound. Guaranteed bounds are often
much wider than empirical errors and may reach one. Resolution is a pitch
contract, not an arbitrary accuracy guarantee. The bound does not certify
continuous gap-free coverage, redundant proposal ratios or the compound
physical-area quadrature used for marginal efficiency/outside-area estimates.

`geometry_projection_error_bound_deg2: null` explicitly declares that physical
approximation and discrepancy from spherical geometry have no sourced numeric
bound. Fidelity/provenance remain separate. Measured reference error never
becomes the guaranteed bound.

## Synthetic mixed-scale and role regressions

The independent fixture uses a 1.4° square and an 8.4″ by 20.4″ rectangle in a
0.05° square selected region. The large footprint contributes a 0.005° west
strip; the small rectangle is fully contained and disjoint from that strip.
The independent area fraction is
`(0.005*0.05 + (8.4/3600)*(20.4/3600)) / 0.05² = 0.1052888889`.

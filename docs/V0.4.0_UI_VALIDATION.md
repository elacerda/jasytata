## Audit and resulting browser behavior

The Gate 7A browser already held registered scientific profiles, row PA,
placement provenance and a geometry context. Missing presentation included
durable evidence, separate PA-policy controls, selectable sequence basis,
scientific tile identity, explicit observed/legacy metric labels, and useful
under-resolution/sampling diagnostics. The sequence default was implicit;
the metrics guard displayed raw unavailable enums. The inspector displayed
coordinates and arbitrary metadata without the profile's scientific meaning.

## Accessibility, viewport and design

New PA/select/checkbox inputs have persistent labels; PA fields expose
requiredness and invalid values. Native select/optgroups and details/summary
retain keyboard operation. DOM tests validate labels, focusable summary,
collapsed/open disclosure state, readable source links, and text alert/status
semantics. Scientific status never depends on color or hover. jsdom does not
execute native summary Enter activation; native HTML supplies that behavior.

The existing viewport-constrained panel architecture, scroll behavior and fonts
are unchanged. Added styling supports wrapped readouts, unit-bearing numbers,
11 px scientific text, focus outlines and links. No new fixed-height card,
nested scroll region or modal is introduced. Impeccable's mechanical detector
reported only the pre-existing Inter warning at `styles.css:3`, left intact.

No browser surface was exposed by computer-use inventory. The Vite server ran,
but manual screenshots, visual inspection at zoom/breakpoints and assistive
technology testing were unavailable. Automated browser regressions run React
in jsdom with the real local APIs/science and an isolated Aladin renderer.
This record makes no claim of a manual visual or screen-reader pass.

## Post-Gate 8 release-smoke UX correction — 2026-10-01

A first release smoke review found no in-app New project action and no clear
distinction between automatic regional planning, manual instrument pointings,
and sequence-bearing strategies. The UI now starts a clean project in place
with confirmation when project content exists, and derives its Planning mode,
available actions, and next-step guidance from registered profile and strategy
semantics. Unsupported automatic region planning is explicit; an observing
sequence is not presented as a regional tiling policy. S-PLUS retains its
existing Complete/Efficient regional workflow. No schema, profile, geometry,
sampling, coverage or planner behavior changed. Manual strategies retain their
existing geometry measurement as “Measure area” / “Region diagnostics,” with
no Generate plan or Complete/Efficient controls. Empty-state and selector text
distinguish instruments, regional strategies and ordered exposure sequences.

Reset clears catalogues/mapping, pointings in every output context (including
disabled rows), previews/context, region, metrics/refusals, selection, import
drafts/PA consent, project PA/basis/epoch/strategy overrides and diagnostics.
